# Designing Assignments AI Can’t Ruin
### Authentic Learning with Gemini

**Google for Education at NYSCATE 2026**

A professional learning resource for educators seeking to design authentic learning experiences and meaningful assessments in the age of artificial intelligence.

Rather than focusing on preventing AI use, these resources explore how intentional instructional design can make student understanding, critical thinking, decision-making, and independent application more visible.

## Explore the Resources

- Prepare, Disrupt, Demonstrate assessment framework
- Five instructional design strategies
- Cross-curricular classroom examples
- Copy-ready Gemini prompts for teachers and students
- Interactive assignment redesign tool
- Assessment strategies and implementation guidance
- Embedded session presentation and downloadable PDF

## About the Website

This responsive, standalone website is built using HTML, CSS, and JavaScript and hosted through GitHub Pages. No additional frameworks or dependencies are required.

The presentation is embedded directly from Google Slides, allowing published updates to appear on the website. The downloadable PDF is a separate snapshot of the instructional presentation.

## Deployment

To host the website using GitHub Pages:

1. Upload the website files to the root of a public GitHub repository.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Save the configuration.
